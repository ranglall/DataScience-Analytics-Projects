# Data Science & Analytics Projects I've worked on

**[Bird Call Nueral Network Predictor](https://github.com/ranglall/BirdCall-NeuralNetwork)**
- Built multiple ML and neural‑network models to classify bird species from short bird-call audio clips.
- Used Jupyter Notebook to create and compare Keras, PyTorch, and KNN models, tuning with Optuna.

**[Microbialites Database System](https://github.com/ranglall/Microbialites)**
- Modernized a legacy Microsoft Access database by implementing a SQL backend and Python user interface.
- Collaborated with geology experts to migrate data, model unfamiliar scientific data structures, and create a user-friendly system with role-based access and long-term maintainability.
  
**[AASHE STARS Sustainability Data Analysis](https://github.com/ranglall/AASHE-STARS-Sustainability-Data-Analysis)**
- Analyzed AASHE STARS sustainability using R and the ‘tidyverse’ library to benchmark university performance.
- Delivered actionable data insights to the Sustainability Department to inform campus-wide strategic planning.

**[Airline Delay Data Analysis](https://github.com/ranglall/AirlineDelay-DataAnalysis)**
- Identified latent patterns and predictive factors contributing to airline delays through large-scale data modeling.
- Applied R, EFA, and SEM to conduct statistical analysis and feature engineering on a 1M+ record dataset.

**[Modeling Athletics Recruitment Expenses](https://github.com/ranglall/AthleticRecruitmentExpenses-DataPrediction)**
- Developed a multiple linear regression model to predict collegiate athletic recruitment spending, - Identified key financial drivers explaining 79.72% of data variability using R, Quarto, and log transformations.

**Cultural Awareness & Implicit Bias Training**
- Supporting social impact research by analyzing multi-year survey data in R to evaluate the impact of implicit bias and cultural awareness police training across officer demographics.
- Clean, organize, and visualize training datasets to uncover equity-related trends in law enforcement education.

**Lumen Christi Catholic Church Survey Data**
- Volunteered with Lumen Christi Catholic Church to clean and analyze survey data in R.
- Built a Likert-scale Tableau visualization in Tableau summarizing well‑being feedback from resource users.
